RESTModel把接口，组织成资源。

以声明约束能力，以资源连接关系，以链式调用表达请求。

开始使用
浏览 API

从资源出发

显式声明集合、成员、单体和关系，沿着业务结构调用接口。

能力由你声明

操作白名单、可复用预设和特殊动作，将允许的调用写进契约。

适配服务约定

用 scheme 统一身份、响应信封和分页规则，跨资源复用。

执行器自由组合

内置 Fetch，按需接入 Axios、HTTP Mock 和 Pinia，核心保持独立。

一次声明，自然调用 ​

ts
import { createClient, fetchTransport, resource } from '@restmodel/restmodel';

const api = createClient({
  baseURL: 'https://example.test/api',
  transport: fetchTransport(),
  resources: { users: resource({ operations: ['list', 'get', 'patch'] }) },
});

const users = await api.users.page(1, 20).list();
const user = await api.users(0).get();
await api.users(0).patch({ name: 'Ivan' });

示例需实际 REST 服务。主包与扩展面向公共发布，目前使用工作区或本地 tarball；快速上手提供无需网络的完整例子。
